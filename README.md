# 🧮 React Calculator App

A responsive and user-friendly calculator built using **React** and **Tailwind CSS**.  
It supports basic arithmetic operations like addition, subtraction, multiplication, and division with real-time display updates and error handling.

---

## 🚀 Features

- Interactive button-based number and operator input  
- Real-time expression display  
- Supports `+ - * /` operations  
- Clear button to reset input  
- Evaluation using `=` button  
- Error handling for invalid expressions  
- Built with **React Hooks (useState)**  
- Clean UI with Tailwind CSS

---

## 🛠️ Tech Stack

- React.js  
- JavaScript  
- Tailwind CSS
